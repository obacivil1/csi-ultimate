# local-lab — منصة تعلم اختبارات الاختراق المحلية

منظومة كاملة داخل جهازك فقط (loopback): موقع هدف + سكريبت فحص + واجهة رسومية + تقارير.
تُنقل كاملةً إلى أي لابتوب تملكه — وثيقة، تعمل بدون إنترنت بعد التثبيت الأول.

## البدء (هذا الجهاز الحالي)

```powershell
python local-lab/target/app.py          # أو: python local-lab/run_target.py
# افتح المتصفح: http://127.0.0.1:5001

# --- الواجهة الرسومية (أسهل طريقة) ---
python local-lab/gui/app.py

# --- سطر الأوامر ---
python local-lab/scanner/local_scan.py --target http://127.0.0.1:5001/
# بدون --mode يستشيرك أولًا. الأنماط: detect / verify / full
```

## الواجهة الرسومية v4 (gui/app.py)

تبويبات بأسلوب Burp: **🏠 اللوحة** (بطاقة هدف + اختبار اتصال + شارة نطاق + إحصاءات + إجراءات سريعة)، **🔍 الفحص** (بحث + فلتر خطورة + «المؤكدة فقط» + بطاقة ثغرة CVSS/CWE/إصلاح + خيار دخول مسبق)، **🎓 التعلم** (17 درسًا)، **🧰 الأدوات** (8 بطاقات)، **📤 التقارير** (تصدير Bounty + حفظ/استئناف مشاريع + سجل تدقيق). منفذ تشغيل دائم + شريط حالة بالنبض.

| الزر / الخيار | يعمل ماذا؟ |
|---|---|
| `▶ فحص أوتوماتيكي كامل` | يجري كل الفحوصات وينشط الجدول بالأخضر/الرمادي |
| `🎓 تعلم خطوة بخطوة` | يريك 25 درسًا عربية — كل درس يشرح الثغرة والإدخال ولماذا خطر |
| `🌐 افتح في المتصفح` | يفتح خطوة الدرس في المتصفح لتجرّب بنفسك |
| `تحقق عندي الآن` | يجري الفحص الحقيقي للخطوة ويخبرك «أكيد أم لا» |
| `التالي` | ينتقل للدرس التالي |
| `🎯 مهمات عملية` | إثبات سيطرة حقيقي: شعار الموقع، ازرع XSS مخزنة، **اقتحم لوحة التحكم** |
| `👁 ما بعد الاختراق` | ماذا ملكت بعد كل ثغرة + عارض الدليل الحي داخل البرنامج |
| `📋 بطاقة الثغرة` | التفاصيل + CVSS + الأثر + **نسخ/حفظ/اشرحها لي** |
| `🎓 مدرسة النتائج` | (تبويب التعلم) افهم كل نتيجة + تحقق بيدك + خطة 3 مراحل بتقدم محفوظ |
| `🔁 Repeater` | عدّل أي طلب وأعد إرساله وشاهد الاستجابة الخام |
| `💥 Intruder` | احقن قوائم حمولات في موضع FUZZ بحدّ معدل وصنّف النتائج |
| `📡 Proxy` | وكيل التقاط على 127.0.0.1 — سجل كامل + اعتراض + نفق CONNECT + فكّ TLS (ثبّت `data/proxy_ca/ca.pem` في متصفحك) + إرسال للـ Repeater |
| `🕸️ الخريطة` | زاحف النطاق: النقاط + النماذج + البصمة + الترويسات |
| `🔣 الترميز` | مشفّر/مفكّك داخلي (URL/Base64/Hex/HTML/Unicode) |
| `🧩 الإضافات` | اكتشاف وتشغيل فحوصات المجتمع من `plugins/checks/` |
| `🧪 مختبرات` | 13 تمرينًا منهجيًا: نفّذ بيدك ثم تحقق آليًا |
| `📤 تقرير Bounty` | يصدّر MD+HTML بأسلوب HackerOne (CVSS + CWE + خطوات + أدلة) |
| `محلية / مرخّصة` | تبدّل النطاق: جهازك فقط، أو نطاق مصرّح مسجل (يتطلب «أؤكد» عند التسجيل) |
| `＋ نطاق مصرّح` | سجل أي نطاق مصرّح (رابط + بيان البرنامج + «أؤكد») — يُحفَظ في `data/authorized_targets.json` ويظهر في القائمة |

في الوضع المرخّص يعمل **التدقيق العام** (14 فحصًا): زحف واستكشاف ثم فحوصات
غير مُدمّرة — قراءة + GET حميد فقط (كناري لا يُنفَّذ)، **بلا POST/رفع/حذف أبدًا**.
`detect` = سلبي فقط، و`verify` (بصندوق التحقق) = + كناري انعكاس واحد لكل معامل.
ملفات الجلسات والدخول الآلي معطّلة تلقائيًا على النطاقات الخارجية.
CLI: `python scanner/local_scan.py --allow https://site.com --confirm-text "أؤكد" --mode verify`
→ تقارير `reports/scan_report_external.json + .md` (تتضمن سجل التفويض).

### الفحص العميق (بتصريح المالك فقط)
ثلاث بوابات لا يعمل دونها جميعًا: تسجيل النطاق («أؤكد») + تصريح المالك
(زر «أصرّح بالفحص العميق ✓» مع كتابة «أصرّح» — أو سحبها بزر ✗) + نية التشغيل
(صندوق «⚡ فحص عميق» / `--deep`) — كلها مسجلة ومؤرخة في `data/authorized_targets.json`
وتظهر شارتها (🔓/🔒) بجانب الهدف، وتُضمَّن في التقرير.
الخمسة: تجاوز دخول SQLi، صدى echo، حساب `{{7*7}}`، فرق boolean (بلا SLEEP)،
رفع TXT كناري مع إعادة جلبه — كلها بكناري حميد.
حدود معلنة: لا XSS مخزنة خارجيًا (تلويث دائم — يدويًا عبر Repeater)، ولا POST
خارج Deep، وملفات الجلسات معطّلة على النطاقات الخارجية.

## النقل إلى لابتوب آخر (تثبيت مرة واحدة)

1. انسخ مجلد `local-lab` كاملًا إلى الجهاز الجديد.
2. ثبّت بايثون + فلاسك (مرة واحدة):
   ```
   pip install flask
   ```
   (الواجهة والفحص يستخدمان tkinter المدمج — لا يحتاجان تثبيتًا إضافيًا.)
3. نفّذ بخطوتين نفس ما في "البدء" — وغيّر `--target` فقط إن استخدمت منفذًا آخر.

## ما الذي يضمن أمان النطاق

- `scoped.Scope.check_url()` يُشغَّل قبل أي اتصال: loopback أو نطاق مصرح واحد فقط.
- في الوضع المرخّص: لا فحص قبل كتابة «أؤكد»، وأي مضيف خارج القائمة يُرفض بـ `ValueError`.
- اختبار `tests/test_scoped.py` يثبت رفض `google.com`، `1.2.3.4`، والمواقع خارج النطاق المصرح.
- سجل `audit.jsonl` بترابط تجزئة (hash-chain): أي تلاعب لاحق يُكشف.

## منهجية ما قبل الميدان (شهادة الجاهزية)
قبل أي موقع حقيقي نفّذ — CLI أو زر «🛡️ شهادة الجاهزية»:
```
python scanner/local_scan.py --certify
```
تتحقق من 4 أبعاد وتحفظ `reports/readiness_<ts>.json`:
1. **معايرة**: المختبر (25 ثغرة مقصودة) — يجب ≥24 بلا أخطاء.
2. **خصوصية**: موقع مصلَّب وهمي — يجب صفر ثغرات (لا إنذارات كاذبة).
3. **بوابات**: رفض الخارجي/بلا توكيد/المنفذ الخطأ/العميق بلا تصريح (6/6).
4. الحكم: **جاهز ✅** أو **غير جاهز ❌** — لا تطبّق على موقع حقيقي مع ❌.

## منهجية الميدان (موقع حقيقي — خطوة بخطوة)

1. **الشهادة خضراء** (زر 🛡️ أو `--certify`) — وإلا توقف.
2. **التصريح مكتوب**: باونتي (النطاق داخل Scope + القواعد تسمح) أو موقعك (سجّل + أصرّح).
3. **سجّل النطاق** في البرنامج مع بيان البرنامج — القائمة تمنع الخطأ.
4. **اختبار اتصال** → **detect** (اقرأ) → راجع → **verify** (صندوق) → راجع.
5. **العميق** فقط: تصريح مالك + صندوق ⚡ + verify — ويُرفَض دونها.
6. **⏹ إيقاف** متى شئت — التقرير يُبنى بما اكتمل.

**التحقق من المخرجات**: كل ✅ لها دليل + زر 👁 عرض حي + درس تحقق يدوي
(🎓 اشرحها لي). قارن detect مع verify: الجديد الحقيقي فقط يُعتمَد. التقارير + `audit.jsonl` (سلسلة تجزئة) توثق كل شيء.

**التحكم داخل الموقع**: نطاق ثلاثي دقيق + حارس كل طلب + إيقاع مهذب
(0.15s) + عدّاد طلبات معلن + زر إيقاف + سجل تدقيق. detect سلبي،
verify كناري واحد، deep ببوابات — ولا POST خارجي إلا بتصريح.

ملاحظة تشغيل: إن تخطت الاختبارات جماعيًا (≈80 skip) فالمختبر نائم —
أعده بـ `python local-lab/run_target.py`.

## القاعدة الذهبية

هذه المنظومة **لجهازك أولًا**. لأي هدف حقيقي (منصات جوائز) سجّله
«نطاقًا مصرّحًا» (رابط + بيان + «أؤكد») — والمنهج هناك قراءة + GET حميد
فقط: بلا POST/رفع/حذف، وبلا أسرار جلسات خارجية، لأن الإثبات العميق يتطلب
إذنًا صريحًا من مالك الهدف نفسه.
